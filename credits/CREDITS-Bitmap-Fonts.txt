Local Essentials v21.1 integration: scripts/0400-CLI_Bitmap_Fonts.rb.
It intercepts Bitmap text drawing and measurement, adds selected accented
letters/symbols, caches colored sheets, and adapts the standalone BitmapText
API for proper bitmap/viewport disposal. It does not run the bundled Windows
converter executable. Standard bitmap UI text has no drop shadow. Characters
not covered by the bitmap font still use Essentials' TTF renderer rather
than being dropped or replaced with question marks.
