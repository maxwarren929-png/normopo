Original game artwork: Nintendo / Game Freak / Creatures.

Conversion: tools/build_firered_fonts.py, requires Pillow.
Glyph foreground is extracted from palette index 1. The original shadow and
opaque background are excluded. Atlas pixels use nearest-neighbor integer
scaling only: 2x normal/small, 1x tiny, 3x large. Character advances come from
the game's width tables. ASCII punctuation absent from the original character
map has locally drawn pixel shapes. ASCII $ uses the Pokemon currency glyph.

These assets are NOT covered by the CLI's MIT license. No separate permission
to redistribute the original game artwork is claimed. The PNGs and this file
remain in the ignored local game asset tree. Do not include them in a public
release without confirming your rights to do so.

The drawing adapter is based on Hollow_Ego's Bitmap Fonts Scripts approach;
see CREDITS-Bitmap-Fonts.txt for those credits. Its original Power Clear sheets
remain available to the standalone BitmapText API, but are no longer selected
for the standard UI.
